# ⚡ AuylSTEM Lab — Виртуальная STEM-лаборатория микроконтроллеров и робототехники

**Проект для WIT Teens Hackathon 2026 · Кейс №3: «STEM без сложного оборудования»**

Интерактивный веб-симулятор STEM-лаборатории на базе **Arduino Uno** и **ESP32 Wi-Fi**, созданный для учеников сельских и малых городских школ, не имеющих доступа к физическим наборам робототехники и радиоэлектроники.

## 🌟 Ключевые особенности

1. **Полный образовательный цикл:** `Теория → Пошаговая сборка → Программирование C++ → Живой эксперимент → Диагностика ошибок → Практический челлендж`.
2. **8 интерактивных лабораторных работ:**
   - 💡 **Урок 1:** Управление светодиодом (`Blink`) и защита цепи резистором (Закон Ома).
   - 🔘 **Урок 2:** Тактовая кнопка + Светодиод (`digitalRead` и условие `if / else`).
   - 🚦 **Урок 3:** Городской светофор (алгоритмы управления 3 каналами).
   - 🌙 **Урок 4:** Автоматическое освещение села (фоторезистор `LDR` + `analogRead`).
   - 🌡️ **Урок 5:** Климат-контроль (датчик температуры + экран `LCD 16x2` + тревога перегрева).
   - 🚧 **Урок 6:** Умный шлагбаум (ультразвуковой радар `HC-SR04` + сервопривод `SG90`).
   - 🌱 **Урок 7:** АгроТех: Автоматический полив для сельской теплицы (датчик влажности почвы + водяной насос).
   - 📡 **Урок 8:** Сельская IoT-метеостанция на `ESP32 Wi-Fi` (сбор и передача телеметрии).
3. **🧠 Smart STEM Наставник (Анализатор ошибок):**
   - Проверяет замкнутость цепи (`GND`), полярность светодиодов, наличие токоограничивающих резисторов и соответствие пинов между схемой и кодом.
   - Наглядно моделирует «перегорание» светодиода при подключении к 5V без резистора и объясняет физику процесса простым языком.
4. **⚡ Доступность для сельских школ:**
   - `100% Client-Side` (работает прямо в браузере без тяжёлых 3D-движков и трафика после загрузки).
   - Двуязычный интерфейс (`RU / KZ`).
   - Сохранение прогресса (`XP`) и экспорт проектов в `.json`.

## 🚀 Быстрый старт и деплой на Vercel

Проект представляет собой чистое статическое веб-приложение (`HTML5 + CSS3 + Vanilla JS`) без внешних серверных зависимостей.

- **Локальный запуск:** Откройте файл `index.html` в любом современном браузере.
- **Деплой на Vercel:** Подключите репозиторий к Vercel (`Framework Preset: Other`, `Output Directory: .`). Конфигурация уже настроена в файле `vercel.json`.
